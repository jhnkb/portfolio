Determining Effects of Dex in Socs1 Gene in Mice

This project focuses on understanding how dexamethasone (Dex) affects the expression of the Socs1 gene during red blood cell development in mice. Using single-cell RNA and ATAC sequencing data, I compared Socs1 expression between Dex-treated and untreated cells to investigate how the treatment influences gene expression during erythropoiesis.

Workflow & Methods

  1. Initial Socs1 Expression Analysis

    Used R, Scanpy, Seurat, and dplyr to process single-cell RNA-seq data and examine Socs1 expression in BFU-E and Dex-treated cells. Performed Wilcoxon rank-sum tests and used MAST for statistical modeling, accounting for cell type and cellular detection rate.

  2. scRNA-seq Quality Control

    Used SoupX to correct ambient RNA contamination in Dex and NoDex samples. Applied gene count and mitochondrial percentage filters using Seurat, then used Scrublet through Python and R's reticulate package to identify and remove predicted doublets.

  3. scRNA-seq Clustering and Visualization

    Used Seurat to normalize and scale gene expression data, perform principal component analysis (PCA), generate UMAP visualizations, and identify cell clusters using Louvain clustering. Examined erythroid markers including Gypa, Kit, and Tfrc using FeaturePlot and DotPlot.

  4. scATAC-seq Data Preparation and Quality Control

    Used Cell Ranger ATAC outputs, Seurat, and Signac to construct chromatin accessibility objects for Dex and NoDex samples. Incorporated GENCODE gene annotations and evaluated fragment counts, detected features, nucleosome signal, TSS enrichment, and fraction of reads in peaks (FRiP).

  5. scATAC-seq Peak Analysis and Clustering

    Used Signac and GenomicRanges to create a common peak set and quantify chromatin accessibility across both samples using FeatureMatrix. Applied TF-IDF normalization, singular value decomposition (SVD), and latent semantic indexing (LSI), followed by UMAP visualization and clustering in Seurat.

  6. RNA and ATAC Integration

    Used Signac to calculate gene activity scores from chromatin accessibility data. Applied Seurat's integration and label transfer methods to connect RNA expression profiles with ATAC-derived gene activity and investigate cell populations across both modalities.

  7. Downstream Analysis and Visualization

    Used Seurat, Signac, and ggplot2 to explore differences between Dex-treated and untreated cells, visualize cell populations, and investigate gene expression and chromatin accessibility patterns associated with erythroid development.

results

Initial Socs1 analysis identified significant differences in gene expression between BFU-E and Dex-treated cells. I have also completed scRNA-seq quality control, clustering, and visualization, and have begun analyzing scATAC-seq data. This project is ongoing, with further analysis focused on understanding the effects of Dex on erythroid development.
