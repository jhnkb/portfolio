WatchTower - Web Application Monitoring Dashboard

WatchTower is a web-based monitoring application developed as a team project for CSE 110 at UC San Diego. The application helps developers monitor website performance and identify potential issues through a centralized dashboard. I worked primarily with the UX and Product team, focusing on research, interface design, and improving how performance information is presented to users.

Workflow & Methods

  1. Research and Planning

    Collaborated with the team to research existing website monitoring platforms and identify useful features for WatchTower. Helped determine how users could interact with performance metrics and navigate the dashboard.

  2. UX/UI Design

    Worked with the UX and Product team to plan the application's interface and organize performance information. Focused on making the dashboard understandable and accessible to developers.

  3. Performance Dashboard

    Helped develop the design and presentation of the performance dashboard, which displays metrics such as average response time, 95th percentile latency (p95), and time to first byte (TTFB). The interface includes selectable time ranges of 24 hours, 7 days, and 30 days.

  4. Performance Data Collection

    The team developed a lightweight JavaScript collector that records website performance information, including page load time, DOM readiness, server response time, and network timing metrics. These measurements provide the data displayed in WatchTower.

  5. Frontend Development and Integration

    Collaborated with teammates during the development of the web application, connecting the dashboard's interface with the project's performance monitoring features.

  6. Testing and Refinement

    Reviewed the application's interface and functionality throughout development. Worked with the team to refine the dashboard and improve the presentation of performance information.

Results

Our team developed WatchTower as a web application for collecting and displaying website performance information. The dashboard allows users to view performance metrics across different time ranges and uses warning and critical thresholds to help identify potential performance issues.

This project gave me experience working in a collaborative software engineering environment, particularly in UX/UI design, product planning, and translating technical information into a user-friendly interface.
